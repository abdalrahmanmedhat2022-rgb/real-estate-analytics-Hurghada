🏠 Real Estate Analytics Dashboard – Hurghada & Red Sea
Interactive Power BI / Excel dashboard analyzing real estate properties in Hurghada and the Red Sea region.
📊 Dashboard Overview
Key Visuals:
Avg. Price per sqm by Location
Horizontal bar chart showing average price per square meter across different compounds and areas (Um Jamar, Selena Bay Resort, Sabina, Nubia, Katameya Heights, Fanadir Marina, Cyan, Ancient Sands Resort, Abu Tig Marina, etc.)
Avg. Price per sqm by Property Type
Combined bar + line chart comparing average price/sqm and number of units across property types:
Apartment, Built Sale Unit, Bungalow, Cabin, Chalet, Duplex, Full Floor, Hotel-Apartment, Land, Palace, Penthouse, Roof, Townhouse, Twin House, Villa, Whole Building
Total by Payment Method
Pie chart showing distribution between:
Installments (majority)
Cash
Other
Total Value by Property Type
Bar chart highlighting total market value, with Land being the dominant category.
